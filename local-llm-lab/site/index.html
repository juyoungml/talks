로컬 LLM 실험실

PyTorch로 만드는 추론 엔진

Ollama 안을 열어보자

회의록을 붙여 넣고 엔터를 쳤더니, 인터넷 연결도, API 키도 없이 노트북이 요약을 써 내려가기 시작합니다.

설치 한 줄, 명령 한 줄이면 끝입니다. 그런데 이 안에서 무슨 일이 일어나는지는 막상 잘 모르죠. 맨 아래 숫자도 그렇습니다. eval rate 78.64 tokens/s는 빠른 걸까요, 느린 걸까요? 무엇이 이 숫자를 정할까요?

이 글에서는 이걸 직접 만들어 보겠습니다. 재료는 Hugging Face에 공개된 1.5GB짜리 가중치 파일 하나와 PyTorch뿐입니다. 같은 모델, 같은 회의록으로 시작해서 Ollama처럼 답을 써 내려가게 만들고, 마지막에는 Ollama 옆에 나란히 놓고 속도를 재 볼 것입니다.

눈치챘겠지만 모델은 "세 가지"만 정리하라는 말을 무시하고 회의록을 통째로 다시 썼습니다. 0.6B는 아주 작은 모델이라 그렇습니다. 이 글에서 관심 있는 건 답이 얼마나 좋은지가 아니라, 답이 어떻게 나오는지입니다.

이 글의 순서

  1. 1부 · 일단 만들기
  2. 01 첫 토큰 꺼내기가중치 파일에서 첫 글자 하나를 꺼낸다
  3. 02 한 토큰씩 이어 쓰기답이 나온다. 그런데 너무 느리다
  4. 2부 · Ollama 따라잡기
  5. 03 어디가 느린지 측정하기
  6. 04 계산한 K, V 재사용하기 · KV cache
  7. 05 attention 커널 바꾸기 · SDPA
  8. 06 메모리 미리 잡아두기 · static cache
  9. 07 파이썬 오버헤드 줄이기 · compile
  10. 08 가중치를 INT8로 줄이기
  11. 09 다시 Ollama와 비교하기
따라 하려면

Apple Silicon Mac 기준입니다. MPS가 없으면 자동으로 CPU에서 돌아갑니다(느립니다). 처음 실행할 때 가중치 1.5GB를 받습니다.

git clone … && cd local-llm-lab
uv sync --python 3.12
uv run python steps/01_first_token.py

Ollama와 비교하고 싶다면 brew install ollama 후 ollama pull qwen3:0.6b-fp16.
