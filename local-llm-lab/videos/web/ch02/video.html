steps/02_generate.py · demo_sampling
def sample(logits, temperature=0.6, top_k=20, top_p=0.95):    probs = (logits.float() / temperature).softmax(-1)    probs, idx = probs.topk(top_k)              # 상위 20개만 남기고    keep = probs.cumsum(-1) - probs < top_p     # 누적 95% 안쪽만 남긴다    probs = probs * keep    choice = torch.multinomial(probs / probs.sum(), 1)    return idx.gather(-1, choice)

1등이 더 유리해집니다

top_p위에서부터 더해 95%까지만 남깁니다

    
multinomial남은 확률대로 뽑습니다 (sampling)
