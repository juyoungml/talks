# 최종 프로젝트

세 트랙 중 하나를 골라 공개 저장소로 제출합니다. 통과하면 검증 ID가 있는 수료증을 받습니다.

속도는 기계마다 다르므로 모든 기준은 **내 기계에서 잰 비교값**입니다. 아래 숫자(M3 Pro)는 참고용입니다.

---

## 트랙 A · 첫 토큰 줄이기

지금 엔진의 첫 토큰은 220 ms, `qwen3:0.6b-fp16`은 151 ms입니다. 원인 중 하나는 prefill이 실제 길이(638칸)가 아니라 버퍼 전체(1,024칸)를 보고 mask로 가리는 것입니다.

```python
def causal_mask(pos):
    k = torch.arange(MAX_LEN, device=device)[None, :]
    return k <= pos[:, None]
```

**과제**: prefill만 실제 길이를 보는 경로를 따로 만듭니다. decode는 고정 버퍼와 컴파일을 그대로 씁니다. 여유가 있으면 prefill 컴파일도 시도합니다.

**통과 기준**
- 내 기계에서 `steps/08_int8.py` 대비 첫 토큰 시간 감소를 5회 중앙값으로 보고합니다.
- 생성된 48토큰이 `steps/08_int8.py`와 같습니다.
- decode tok/s가 떨어지지 않았습니다(5% 이내).

## 트랙 B · 다른 모델에 적용

**과제**: Qwen3 계열의 더 큰 모델(예: `Qwen/Qwen3-1.7B`)에 KV cache, SDPA, 고정 버퍼, 컴파일, INT8을 적용합니다. 층 수, 헤드 수, 차원은 `config.json`에서 읽으므로 대부분 그대로 동작하지만, `tie_word_embeddings`가 `false`인 모델은 출력에 `lm_head.weight`를 따로 써야 합니다.

**통과 기준**
- 첫 토큰이 Hugging Face Transformers 공식 구현과 같습니다(점수 최대 차이도 보고).
- 캐시 없는 생성 대비 decode 배수를 보고합니다.
- 스텝당 읽는 양(층 행렬 + lm head + KV 버퍼 바이트), 실효 GB/s(= 읽는 양 × tok/s), 천장 대비 %(= 실효 ÷ 이론 대역폭)를 계산합니다.
- 같은 모델을 Ollama로도 받을 수 있다면 같은 조건으로 비교합니다.

---

## 트랙 C · 대역폭 천장에 다가가기

지금 엔진은 스텝마다 약 870 MB(INT8 층 행렬 441 + lm head 311 + KV 버퍼 117)를 읽고 80 GB/s를 씁니다.

**과제**: 읽는 양을 줄이거나 읽는 효율을 올립니다. 예: KV 버퍼에서 채운 칸만 읽기, lm head 양자화, 4비트 가중치 실험.

**통과 기준**
- 같은 계산식(읽는 양 × tok/s)으로 바꾼 뒤의 스텝당 읽는 양과 실효 GB/s를 보고하고, `steps/08_int8.py` 대비 변화의 원인을 설명합니다.
- 48토큰 출력이 달라졌다면 처음 달라진 위치와 그 위치의 1등·2등 점수 차이를 보고합니다.

## 제출물 (모든 트랙 공통)

1. **공개 저장소**: 코드와 커밋 기록. 한 번에 올린 커밋 하나보다 작업 과정이 보이는 기록을 권합니다.
2. **실행 로그 원문**: 아래 명령의 출력을 맨 앞에 붙입니다.

```bash
uv run python -c "import torch, platform; print(platform.platform(), platform.processor(), torch.__version__)"
```

3. **`REPORT.md`**: 무엇을 바꿨는지, 숫자가 어떻게 변했는지(표), 왜 그렇게 변했는지. 숫자는 모두 내 기계의 실행 로그에 있어야 합니다.
4. **강별 속도 기록**: 내 기계에서 아래 여섯 개를 실행한 출력 원문. 각 출력의 `이후 N tok/s` 줄이 수료증에 그대로 들어갑니다(2강의 값 → 8강의 값과 막대 그래프).

```bash
for s in 02_generate 04_kv_cache 05_sdpa 06_static_cache 07_compile 08_int8; do uv run python steps/$s.py; done
```

판정은 통과 또는 보완 두 가지입니다. 보완이면 빠진 항목을 적어 돌려드립니다.
